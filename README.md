# AERO HUB

Сайт-візитка з каталогом продукції. Фронтенд — статичний HTML на GitHub Pages, бекенд — Google Apps Script Web App поверх Google Таблиці.

## Структура репозиторію

- `index.html` — головна сторінка.
- `product-tetris.html`, `product-tetrisplus.html` — сторінки опису окремих товарів.
- `news.html` — сторінка новин.
- `admin.html` — панель редагування контенту (товари, новини, медіа, партнери, тексти сторінок) без доступу до Google Таблиці чи GitHub. Захищена паролем, заданим у `Code.gs` (`ADMIN_PASSWORD`).
- `Code.gs` — код бекенду. Джерело істини — код у редакторі Apps Script, прив'язаному до робочої Google Таблиці; цей файл — його копія для версійного контролю.
- `products.json` — статичний знімок товарів для швидкого першого відображення сайту (див. `update-products-json.md`).
- `Товари.csv`, `Налаштування.csv` — приклади структури відповідних листів Google Таблиці.

## Редагування контенту

- Товари, новини, медіа, партнери, тексти сторінок і контакти редагуються через `admin.html` або напряму в Google Таблиці (листи «Товари», «Новини», «Медіа», «Партнери», «Налаштування»).
- Заявки з форми замовлення потрапляють у лист «Замовлення» і дублюються на email з поля `email` листа «Налаштування».
- Кілька фото на одному товарі: у колонці `image_url` перелічити посилання через кому — сайт покаже міні-галерею з переглядом на весь екран.
- Категорія товару (`category`): `ground`, `air`, `comms`, `reb`. Технічні характеристики (`details`): список пунктів через `|`.

## Зміни в Code.gs

Після редагування коду в редакторі Apps Script потрібна нова версія розгортання: **Розгорнути → Керування розгортаннями → значок олівця → Нова версія → Розгорнути**. Без цього кроку сайт продовжує звертатись до попередньої версії коду. Оновлену копію файлу варто так само закомітити сюди, в `Code.gs`.

## Дизайн

Кольори, шрифти й розташування блоків — у блоці `<style>` на початку `index.html`. Основний колір задається змінною `--accent`.

## Типові проблеми

- **Товари не завантажуються** — перевірити, що `API_URL` в `index.html` відкриває JSON, а не сторінку помилки; у налаштуваннях розгортання Apps Script має бути «Хто має доступ: Усі».
- **Заявки не приходять на пошту** — перевірити поле `email` в листі «Налаштування» і теку «Спам».
- **Зміни в `Code.gs` не діють** — потрібна нова версія розгортання (див. вище).
