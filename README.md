# Сайт-візитка — інструкція із запуску

Ти отримав(-ла) 4 файли:

- `index.html` — сам сайт (одна сторінка)
- `Code.gs` — код бекенду (Google Apps Script)
- `Товари.csv` — приклад товарів для Google Таблиці
- `Налаштування.csv` — приклад текстів/контактів для Google Таблиці

Витрати на запуск: **0 грн**. Знадобиться лише Google-акаунт та (на кроці 4) акаунт на GitHub.

Просто відкривши `index.html` двічі клікнувши на файл, ти вже побачиш робочий сайт із демо-товарами — це зручно, щоб одразу оцінити вигляд. Але заявки з форми поки нікуди не надходитимуть, поки не пройдеш кроки нижче.

---

## Крок 1. Створи Google Таблицю

1. Зайди на [sheets.google.com](https://sheets.google.com) і створи нову таблицю. Назви її, наприклад, «Мій сайт — дані».
2. Перейменуй перший лист (вкладку внизу) на **Товари** і заповни його за зразком `Товари.csv` (можна імпортувати: Файл → Імпортувати → Завантажити → обрати `Товари.csv` → «Замінити дані в поточному аркуші»).
   - Колонка `active`: постав `no`, якщо товар треба тимчасово приховати з сайту.
   - Колонка `category`: визначає, у який розділ «Продукції» потрапить товар. Допустимі значення: `ground` (Наземні роботизовані комплекси), `air` (Безпілотні літаючі апарати), `comms` (Засоби зв'язку), `reb` (РЕБ). Якщо залишити порожньою, сайт спробує вгадати категорію за назвою товару — але надійніше вказувати її явно.
   - Колонка `price`: якщо ціну ще не визначено, залиш порожньою або впиши «Ціну уточнюйте» — сайт сам покаже цей напис для товарів без ціни.
   - Колонка `details` (необов'язкова): список технічних характеристик у форматі `пункт 1 | пункт 2 | пункт 3` — сайт покаже їх у розкривному блоці «Детальніше» на картці товару.
3. Додай другий лист, назви його **Налаштування**, заповни за зразком `Налаштування.csv` (так само через імпорт).
   - `email` — саме на цю адресу приходитимуть заявки з форми замовлення.
4. Заявки з форми сайту автоматично з'являться на третьому листі **Замовлення** — його створювати не потрібно, бекенд зробить це сам при першій заявці.

Редагувати товари, тексти й контакти надалі — просто відкривай цю таблицю і міняй клітинки. Сайт підхоплює зміни автоматично при кожному відкритті.

## Крок 2. Розгорни бекенд (Apps Script)

1. У цій-таки Google Таблиці: **Розширення → Apps Script**.
2. Видали весь код-заглушку, що там є, і встав повністю вміст файлу `Code.gs`.
3. Збережи (значок дискети або Ctrl+S).
4. Натисни **Розгорнути → Нове розгортання**.
   - Тип: **Веб-додаток**.
   - Опис: будь-який.
   - "Виконати від імені": **Мене**.
   - "Хто має доступ": **Усі**.
5. Натисни **Розгорнути**. Google попросить надати дозволи — погодься (це твій власний скрипт, він працює лише з твоєю таблицею й твоєю поштою).
6. Скопіюй **URL веб-додатку** — виглядає приблизно так:
   `https://script.google.com/macros/s/AKfycb.../exec`

   Перевір його прямо в браузері — за посиланням має відкритись сторінка з JSON-даними твоїх товарів.

> Якщо пізніше зміниш код `Code.gs`, потрібно зробити **Розгорнути → Керування розгортаннями → значок олівця → Нова версія → Розгорнути**, інакше сайт бачитиме стару версію коду.

---

## Крок 3. Підключи сайт до бекенду

1. Відкрий `index.html` у будь-якому текстовому редакторі (Блокнот, VS Code тощо).
2. Знайди рядок (майже на самому початку `<script>`):
   ```js
   const API_URL = ""; // <-- встав сюди URL розгорнутого Apps Script
   ```
3. Встав туди URL з кроку 2:
   ```js
   const API_URL = "https://script.google.com/macros/s/AKfycb.../exec";
   ```
4. Збережи файл і відкрий `index.html` у браузері — тепер мають підʼявитись твої реальні товари й тексти з таблиці, а форма замовлення — надсилати заявки на пошту.

## Крок 4. Виклади сайт в інтернет (безкоштовно)

Найпростіший варіант — **GitHub Pages**:

1. Зареєструйся на [github.com](https://github.com) (якщо ще нема акаунту).
2. Створи новий репозиторій (кнопка **New**), назви як завгодно, зроби його **Public**.
3. Завантаж туди файл `index.html` (кнопка **Add file → Upload files**).
4. Перейди в **Settings → Pages**, у розділі **Source** обери гілку `main` і папку `/root`, натисни **Save**.
5. Через 1–2 хвилини сайт зʼявиться за адресою на кшталт:
   `https://твій-нік.github.io/назва-репозиторію/`

Альтернатива — **Netlify Drop** ([app.netlify.com/drop](https://app.netlify.com/drop)): просто перетягни файл `index.html` у вікно браузера — і за кілька секунд отримаєш робоче посилання, без реєстрації на GitHub. Мінус — без акаунту посилання може бути тимчасовим, тож для постійного сайту краще все ж завести акаунт (безкоштовний) і задеплоїти через нього.

Свій домен (наприклад `mysite.com.ua`) можна докупити окремо в будь-якого реєстратора (~200–400 грн/рік) і підключити його як до GitHub Pages, так і до Netlify — це вже опціонально.

## Кілька фото на одному товарі

У колонці `image_url` можна вказати не одне посилання, а кілька — просто через кому:

```
https://посилання-на-фото-1.jpg,https://посилання-на-фото-2.jpg,https://посилання-на-фото-3.jpg
```

Сайт сам покаже це як міні-галерею на картці товару (стрілки ‹ › та крапки знизу, щоб перемикати фото), а клік на фото відкриє його на весь екран із можливістю гортати. Якщо посилання одне — все виглядає як і раніше, без стрілок. Кількість фото не обмежена.

## Як далі редагувати сайт

- **Товари, ціни, опис, фото** → редагуй лист «Товари» в Google Таблиці.
- **Текст «Про нас», телефон, email, соцмережі, заголовок на головній** → лист «Налаштування».
- **Заявки клієнтів** → лист «Замовлення» (там же можна вести облік, кому вже відповіли).
- Дизайн (кольори, шрифти, розташування блоків) — у файлі `index.html`, у блоці `<style>` на початку файлу. Основний колір задається змінною `--accent` (перший рядок стилів).

## Можливі проблеми

- **Товари не завантажуються на сайті** — перевір, що `API_URL` вставлено правильно (без зайвих пробілів) і що при переході за цим посиланням у браузері відкривається JSON, а не сторінка помилки. Якщо просить логін — перевір, що при розгортанні обрано «Хто має доступ: Усі».
- **Заявки не приходять на пошту** — перевір, що в листі «Налаштування» заповнене поле `email`, і подивись лист «Замовлення» — якщо рядок там зʼявився, а листа нема, перевір теку «Спам».
- **Змінив код `Code.gs`, але нічого не змінилось** — потрібно створити нову версію розгортання (див. примітку в кінці Кроку 2).
