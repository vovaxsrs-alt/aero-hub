# Як оновити products.json

`products.json` — це «фотографія» даних із твоєї Google Таблиці, яка лежить просто на сайті (поруч із `index.html`). Вона потрібна лише для того, щоб сайт міг **миттєво** показати товари при найпершому відкритті (поки в браузера відвідувача ще немає збереженого кешу) — не чекаючи, доки «прокинеться» Google Apps Script.

**Важливо:** навіть якщо цей файл давно не оновлювався, сайт однаково завжди підвантажує актуальні дані з таблиці у фоні — за секунду-дві після відкриття картки товарів самі оновляться, якщо щось змінилось. Тобто застарілий `products.json` нічого не ламає, він лише трохи сповільнює саму першу секунду показу. Тому оновлювати його часто не обов'язково — головне робити це після великих змін (додав багато нових товарів, поміняв ціни/фото майже всюди, приховав/показав велику кількість позицій).

## Кроки

1. Відкрий у браузері посилання на свій Apps Script — те саме, що вписане в `index.html` як `API_URL` (закінчується на `/exec`). Просто встав його в адресний рядок і натисни Enter. Побачиш «сирий» текст JSON з усіма товарами й налаштуваннями.
2. Виділи весь текст на сторінці — `Ctrl+A`, потім скопіюй — `Ctrl+C`.
3. Відкрий Блокнот (Notepad) або будь-який текстовий редактор і встав туди (`Ctrl+V`) весь текст.
4. Збережи файл під іменем рівно `products.json` (важливо: розширення саме `.json`, не `.txt`). У Блокноті при збереженні вибери «Тип файлу: Усі файли (\*.\*)» і впиши ім'я `products.json`.
5. Зайди на https://github.com/vovaxsrs-alt/aero-hub
6. Перетягни збережений файл `products.json` просто на сторінку репозиторію (або натисни **Add file → Upload files** і вибери файл). GitHub сам побачить, що файл із такою назвою вже є, і запропонує замінити його вміст.
7. Внизу сторінки лиши позначку **Commit directly to the main branch** (вона й так стоїть за замовчуванням) і натисни зелену кнопку **Commit changes**.
8. Через 30–60 секунд сайт передеплоїться сам (GitHub Pages робить це автоматично) — перевірити можна тут: https://vovaxsrs-alt.github.io/aero-hub/

Жодних паролів, токенів чи додаткових акаунтів для цього не треба — тільки той самий GitHub-акаунт, у якому ти вже залогінений.
