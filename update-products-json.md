# Оновлення products.json

`products.json` — статичний знімок даних із Google Таблиці, що лежить поруч з `index.html`. Використовується для миттєвого показу товарів при першому завантаженні сторінки, до того як сайт підвантажить актуальні дані з Apps Script у фоні. Застарілий файл нічого не ламає — він лише трохи сповільнює саму першу секунду показу товарів; оновлювати його варто після великих змін (багато нових товарів, масова зміна цін/фото, приховання чи показ великої кількості позицій).

## Кроки

1. Відкрити в браузері `API_URL` — те саме посилання, що вказане в `index.html` (закінчується на `/exec`). Сторінка покаже JSON з товарами й налаштуваннями.
2. Виділити весь текст (`Ctrl+A`, `Ctrl+C`).
3. Вставити в текстовий редактор і зберегти файл під іменем `products.json` (розширення саме `.json`).
4. На https://github.com/vovaxsrs-alt/aero-hub завантажити файл через **Add file → Upload files** — GitHub запропонує замінити наявний `products.json`.
5. Закомітити в гілку `main`. GitHub Pages передеплоїть сайт автоматично протягом хвилини; перевірити можна на https://vovaxsrs-alt.github.io/aero-hub/.
